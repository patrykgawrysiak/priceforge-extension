# PriceForge

> **Stop overpaying for games.**

PriceForge is a Steam browser extension that analyses a game's current price against its recent and historical pricing to help answer one simple question:

**Is now a good time to buy?**

## What it does

* Tracks current Steam prices
* Analyses recent price history
* Identifies typical sale prices
* Detects recent price changes
* Compares prices against historical lows
* Generates a clear **BUY NOW / GOOD TIME / WAIT** verdict
* Explains *why* the verdict was given

## How it works

PriceForge uses price-history data from **IsThereAnyDeal** and its own **Verdict Engine** to turn raw pricing data into a simple recommendation.

Instead of just showing another price comparison, PriceForge aims to give you the context behind the price.

## Status

🚧 **Early development**

PriceForge is currently being developed as a Steam browser extension with a hosted API planned for future releases.
